# Python Tic-Tac-Toe 🎮

A simple, interactive command-line implementation of the classic Tic-Tac-Toe game built with **Python 3**. Play locally with a friend, featuring full input validation and a replay loop.

## Features ✨
* **Two-Player Local Play**: Take turns playing as **X** and **O**.
* **Robust Input Validation**: Prevents invalid inputs (letters, out-of-range numbers) and blocks moves on already-taken squares.
* **Win & Tie Detection**: Automatically checks for horizontal, vertical, and diagonal winning lines, or declares a tie if the board fills up.
* **Replay Option**: Option to start a new game immediately after one concludes.

## Requirements 📋
* Python 3.x installed on your machine.

## How to Run 🚀
1. Clone the repository or download the `tic_tac_toe.py` file.
2. Open your terminal or command prompt.
3. Run the script using Python:
   ```bash
   python tic_tac_toe.py
   
## How to Play 🕹️
The game displays a 3x3 grid numbered from 1 to 9.
Players alternate turns choosing a number corresponding to the square where they want to place their mark (X or O).
